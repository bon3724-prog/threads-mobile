처음 한 번: GitHub 토큰 연결

이 화면은 GitHub의 대기열(threads-queue)을 직접 고쳐요. 그러려면 그 저장소에만 쓸 수 있는 토큰이 필요해요. 토큰은 이 휴대폰 브라우저에만 저장돼요.

  1. GitHub 새 토큰 만들기를 눌러요 (Fine-grained token)
  2. Token name: threads-mobile, Expiration: 원하는 기간
  3. Repository access: Only select repositories → threads-queue
  4. Permissions → Repository permissions:
    · Contents: Read and write (필수)
    · Actions: Read and write (지금 바로 올리기용)
    · Variables: Read-only (PC 켜짐 표시용)
  5. Generate token → 나온 토큰(github_pat_…)을 복사해 아래에 붙여넣어요
